## 题目

判断一个数是不是"快乐数"：

- 每次把数字替换成它**各位数字的平方和**
- 如果最终得到 **1** → 快乐数 ✅
- 如果陷入**死循环** → 不是快乐数 ❌

```
示例：19 → 1²+9²=82 → 8²+2²=68 → 6²+8²=100 → 1²+0²+0²=1 ✅
示例： 2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 (循环) ❌
```

## 核心思路：用 set 检测循环

两种结局：**到 1** 或 **进循环**。只要用一个集合记录出现过的数，重复出现就是死循环。

## 代码 + Python 语法拆解

```python
class Solution:                      # Python 3 不需要写 (object)，默认继承
    def isHappy(self, n: int) -> bool:  # n: int 参数类型, -> bool 返回值类型
        def next_num(num: int) -> int:  # 内部函数也可以用类型提示
            """计算各位数字的平方和"""
            total = 0               # 变量不需要声明类型
            while num > 0:          # while 条件: — 条件为 True 时循环
                digit = num % 10    # % 取模 — 拿个位数
                total += digit * digit  # += 自加赋值
                num //= 10          # //= 整除赋值 — 去掉个位
            return total            # return 返回值，函数结束

        seen = set()                # set() 创建空集合 — 哈希表，in 查找 O(1)
        while n != 1:               # != 不等于 — 没到 1 就继续
            if n in seen:           # x in set — 查重，O(1)
                return False        # 重复了 → 死循环 → 不是快乐数
            seen.add(n)             # set.add(元素) — 加入集合
            n = next_num(n)         # 计算下一轮
        return True                 # 退出 while → n==1 → 是快乐数
```

## 关键语法回顾

| 语法 | 说明 |
|------|------|
| `set()` | 创建空集合，元素不重复 |
| `x in set` | 检查元素是否在集合中，**O(1)** |
| `set.add(x)` | 往集合加元素 |
| `num % 10` | 取模，得个位数 |
| `num //= 10` | 整除赋值，去掉个位（`//` 是整除，`/` 是浮点除法） |
| `total += x` | 自加，等价于 `total = total + x` |
| `while 条件:` | 条件为 True 时循环 |
| `def f(self, n):` | self 是实例引用，调用时不用传 |

## 为什么用 set 而不是 list？

| | `list` | `set` |
|---|---|---|
| `in` 查找 | O(n) 逐个遍历 | **O(1)** 哈希查表 |
| 重复元素 | 允许 | 自动去重 |

循环可能跑很多轮，用 set 永远秒查，list 越来越慢。

## 复杂度

- **时间**：O(log n) — 每轮数字变短，集合操作 O(1)
- **空间**：O(log n) — 集合最多存所有中间结果
